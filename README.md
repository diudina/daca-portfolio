## Featured Projects

### 1. Customer Segmentation with RFM Analysis

**Tools:** Python, pandas, Plotly

Analysed customer purchasing behaviour and created an RFM segmentation model for 2,540 customers.

The analysis identified five customer groups:

- VIP Champions — 455 customers
- Loyal — 679
- Potential — 759
- At Risk — 529
- Lost — 118

The project demonstrates customer-level feature engineering, segmentation logic, validation and business-oriented visualisation.

### 2. Automated Analytics Pipeline

**Tools:** Python, pandas, Supabase API, Plotly

Built a modular pipeline that:

1. fetches sales and customer data from Supabase,
2. cleans and transforms the data,
3. calculates weekly aggregates and KPIs,
4. validates the results,
5. creates visualisations,
6. exports CSV and HTML outputs.

A test run processed the workflow end-to-end in approximately 0.7 seconds.

This project demonstrates API integration, modular Python, validation, error handling and analytics automation.

→ [View project](./week-8/)

## Analytical Principles

I try to follow several principles in my work:

- understand the data grain before analysing;
- validate results before interpreting them;
- avoid unnecessary joins and transformations;
- distinguish observations from explanations;
- make assumptions and limitations explicit;
- connect every important finding to a business implication;
- prefer reproducible workflows over one-off analysis.
